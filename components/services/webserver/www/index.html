字体管理

将字体文件（.ttf / .otf / .ttc）上传到 SD 卡后，可在此选择设备使用的字体。 未选择或 SD 卡缺该字体时，自动回退出厂内置字体。修改后需重启设备生效。

可从 Google Fonts · Noto Sans SC 下载完整字体（建议 .ttf / .otf），上传到 SD 卡后即可选用。

文件管理

浏览与管理 SD 卡中的文件。点击目录名进入；删除文件夹会递归删除其全部内容，不可恢复。

系统设置

以下为设备级维护操作，请谨慎执行。

清空全部配置（WiFi、天气、屏幕、电源、字体选择、登录密码等）并恢复出厂内置字体， 设备将重新进入首次开机引导。执行后需重新连接设备热点完成配置。

立即重启 ESPaperPlay（配置已自动保存，无需重新设置）。

开机引导

欢迎使用 ESPaperPlay！本向导将引导你完成基本配置，全程约 1 分钟。

设备当前已开启热点，你可以用手机连接后访问本页面；也可以直接在网页上完成全部设置。

设置管理密码（用于保护 Web 管理页，至少 8 位）。

选择设备联网方式。

保存后本热点将关闭，请将手机连接到同一网络后继续访问。

配置和风天气（可选，稍后也能在「天气设置」中修改）。

配置已完成！点击「进入控制台」即可开始使用 ESPaperPlay。

若上一步切换了 WiFi 模式，设备 IP 可能已变化，请重新连接后用新地址访问。
