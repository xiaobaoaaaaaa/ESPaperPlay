# ESPaperPlay UI 设计规范

本文件是 `components/graphics/ui` 页面层开发的强制约束。所有页面代码必须遵循以下
三条基本原则，PR 评审与后续维护均以本文件为准。

## 1. 仅使用纯黑白双色

电子墨水屏只能可靠呈现黑/白两色，任何中间色（灰阶）都会引入残影与刷新抖动。

- 调色板只允许两种颜色：纯黑 `#000000`、纯白 `#FFFFFF`。
- 禁用灰阶：不使用 `LV_COLOR_MAKE` 构造非 0/255 分量，不引用灰色预置色（如
  `lv_palette_grey`）。
- 禁用反色/半透明/阴影效果：`opacity` 保持默认 255，不设置 `shadow`、不叠加
  半透明层。
- LVGL 颜色格式固定为 1-bit（如 `LV_COLOR_FORMAT_MONO`，经
  `espaperplay_gui` 渲染后端统一配置），页面代码不接触颜色深度。
- 高亮/选中态通过“黑白互换”（背景变黑、文字变白）表达，不引入第三色。

## 2. 尽可能避免动画

电子墨水屏刷新以“百毫秒”为单位，动画会在屏幕上留下残影并成倍放大刷新次数，
是性能与观感的主要杀手。

- 页面层不使用 `lv_anim` 系列 API（`lv_anim_t`、`lv_anim_start` 等）。
- 不设置过渡动画：`lv_obj_set_style_transition_*` 保持默认（无过渡）。
- 不创建自带动画的控件：`lv_spinner`、`lv_roller`、`lv_arc`、进度条动画等。
- 状态切换（选中、按压反馈、页面跳转）采用“瞬时重绘”，一次完整刷新完成，不
  做中间帧。
- 若确有动态需求（如时钟秒位），改为周期性**整帧局部刷新**，由页面事件驱动
  `lv_obj_invalidate`，仍禁止逐像素/逐帧动画。
- 渲染后端（`espaperplay_gui`）可能提供强制刷新策略，页面层无需自行叠加动画。

## 3. 元素位置使用百分比而非硬编码像素

目标：同一套页面在 800x480 横屏与 480x800 竖屏（或后续其他分辨率）下自动
自适应，不因像素写死而错位。

- 尺寸与坐标一律用百分比：`lv_pct(50)` 表达“容器宽度的 50%”，禁止硬编码像素
  常量（如 `x = 120`、`width = 640`）。
- 布局优先用 LVGL 布局系统：`LV_FLEX_FLOW_*` / `LV_GRID_*`，配合
  `lv_pct()` 与相对父容器定位（`lv_obj_align` 的 `LV_ALIGN_*`），而非
  `lv_obj_set_pos / lv_obj_set_size` 指定绝对像素。
- 父容器自身尺寸（页面根、卡片容器）由 `lv_pct` 决定；叶子元素（图标、固定
  高度按钮）如必须给像素，仅允许以**相对父容器比例的派生值**计算，或由
  布局系统自动撑开。
- 新增页面时必须在横屏（800x480）与竖屏（480x800）两种方向下各验证一次，
  保证无溢出、无重叠。
- 页面不关心屏幕物理尺寸：从 `espaperplay_gui` 查询当前活动尺寸，所有布局
  基于该尺寸推导，禁止把 800x480 写死在页面层。
